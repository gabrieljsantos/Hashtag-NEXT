# Hashtag-NEXT

*"Este projeto é uma ferramenta de análise de jogadas do jogo da velha, focada exclusivamente em cálculos heurísticos. Os dados das combinações de jogadas até N movimentos são gerados pelo módulo `AI_hga_data_gerador.py` e posteriormente analisados pelo módulo `AI_heuristic_game_analysis.py`."*

*"O sistema permite definir manualmente o estado do tabuleiro e retorna estatísticas detalhadas sobre possibilidades de vitória e as melhores jogadas para cada posição, sem qualquer execução do jogo ou interface gráfica."*

*"O foco desta versão é puramente analítico, destacando a capacidade de gerar, processar e interpretar heurísticas de jogadas com base nos dados existentes."*
